#Importar vídeo pelo link
Cole um link compartilhado do YouTube para reconhecer o vídeo e abrir a prévia.
Selecionar os melhores trechos
Defina o início e o fim de cada clip e organize vários trechos em uma lista.
Formatos para redes sociais
Escolha formatos vertical 9:16, horizontal 16:9 ou quadrado 1:1.
Copiar e assistir aos trechos
Abra o vídeo no ponto escolhido, copie as informações do clip ou remova trechos da lista.
